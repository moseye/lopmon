# Lopmon v0.1 Dicord Bot Planning

## Desired Functionality
- `/create-role-signup` -> Lopmon will create a message that would allow others to sign up for a role. For example I could do /create-role-signup @movie-nights "Sign up for movie night notifications!". Users would interact with this, unsure the best interaction method please research this, in order to add the role to themselves.
- `/role-color <hexcode>` -> Lopmon will assign a purely cosmetic role color based on a given hexcode to the user. The role name will be the hexcode itself, and the role should be hoisted above all other roles so a given user can pick their desired name color.
